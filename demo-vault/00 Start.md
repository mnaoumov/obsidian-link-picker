# Start here

Welcome to the [Link Picker](https://github.com/mnaoumov/obsidian-link-picker/) demo vault.

Link Picker is a note picker you point at a folder and then navigate: pick a folder to descend into it, pick `..` to come back out. Its ranking is deterministic rather than fuzzy, so the note that came first last time comes first again.

**How to try it:** open a note in this vault, put your cursor somewhere, and run **Link Picker: Insert link...**.

Inside the picker, `Enter` on a folder descends into it and `Enter` on `..` goes back up. `Alt + 3` toggles whether subfolder contents are included, `Alt + 4` shows only folders, and `Shift + Enter` creates a note with the name you typed and links to it.
